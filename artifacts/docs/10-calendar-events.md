# Calendar, Holidays, Leave & Overlap

> มุมมองปฏิทินที่แสดงวันหยุด, วันลา, นัดหมาย, บันทึก  
> และช่วยตรวจจับเหตุการณ์ที่ทับซ้อนกัน

---

## 1. สิ่งที่แสดงบนปฏิทินได้

| ประเภท | คำอธิบาย | ตัวอย่าง |
|--------|---------|---------|
| **วันหยุดประจำสัปดาห์** | เสาร์–อาทิตย์ (หรือกำหนดเอง) | ทุกเสาร์–อาทิตย์ |
| **วันหยุดประจำปี** | วันหยุดราชการ / นักขัตฤกษ์ | ปีใหม่, สงกรานต์, แรงงาน |
| **วันลา** | วันลาของผู้ใช้ | ลาป่วย, ลากิจ, ลาพักร้อน |
| **นัดหมาย / อีเวนต์** | มีเวลาเริ่ม–สิ้นสุด | ประชุม, หาหมอ, นัดลูกค้า |
| **บันทึก / โน้ต** | ข้อความของวันนั้น | โน้ตสั้น ๆ |
| **เป้าหมาย (Goal)** | ช่วงวันของเป้าหมาย | ไฮไลต์ทั้งช่วง 30 วัน |
| **รายการการเงิน** | ยอดของวัน (optional) | รายจ่ายวันนี้ |

ผู้ใช้สามารถ **เปิด/ปิด** การแสดงแต่ละประเภทได้ตามต้องการ

---

## 2. การแสดงผลเมื่อมีหลายอย่างในวันเดียวกัน

```
┌─────────────┐
│    15       │
│ 🟥 🟦 🟩    │  ← จุดสีหลายอัน = มีหลายประเภท
│  ⚠ overlap  │  ← มีนัดหมายเวลาซ้อนกัน
└─────────────┘
```

- แต่ละประเภทใช้สีต่างกัน
- วันที่มีเหตุการณ์เวลาทับซ้อน → แสดงเครื่องหมายเตือน
- คลิกเข้าไปแล้วเห็นรายการเรียงตามเวลา พร้อมป้าย “ทับซ้อน”

---

## 3. Overlap Detection (ตรวจจับงานซ้ำซ้อน)

### ตอนสร้าง / แก้ไขนัดหมาย
1. ผู้ใช้ใส่วันที่ + เวลาเริ่ม + เวลาสิ้นสุด
2. ระบบค้นหานัดหมายอื่นที่เวลาซ้อนกันในวันเดียวกัน
3. ถ้ามี → แสดงคำเตือน:
   > “เวลานี้ซ้อนกับ: ประชุมทีม 10:00–11:30”
4. ผู้ใช้เลือกได้ว่าจะบันทึกต่อหรือแก้เวลา

### บนปฏิทิน
- วันที่มี overlap แสดงตัวบ่งชี้ชัดเจน
- ในมุมมอง Day / Week แสดงแถบเวลทับกันให้เห็นภาพ

## 4. ข้อมูลที่ต้องเก็บเพิ่ม

### 4.1 วันหยุดประจำปี (Holidays)

```sql
CREATE TABLE holidays (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name            TEXT NOT NULL,              -- สงกรานต์, ปีใหม่
  holiday_date    DATE NOT NULL,
  year            INTEGER,                    -- สำหรับวันหยุดที่ย้ายปี
  country_code    TEXT DEFAULT 'TH',
  is_recurring    BOOLEAN DEFAULT false,      -- วันเกิดซ้ำทุกปี (เช่น 31 ธ.ค.)
  source          TEXT DEFAULT 'system',      -- system | user
  created_at      TIMESTAMPTZ DEFAULT now()
);
```

- ระบบมีชุดวันหยุดไทยมาให้เริ่มต้น
- ผู้ใช้เพิ่มวันหยุดส่วนตัวได้

### 4.2 วันหยุดประจำสัปดาห์ (ตั้งค่าผู้ใช้)

เก็บใน `settings` หรือตารางเล็ก ๆ:

```text
weekend_days = [6, 0]   -- เสาร์=6, อาทิตย์=0 (หรือกำหนดเอง)
```

### 4.3 วันลา (Leave)

ใช้ตารางอีเวนต์/เรคคอร์ด หรือแยกชัดเจน:

```sql
CREATE TABLE leave_days (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID NOT NULL REFERENCES auth.users(id),
  leave_type      TEXT NOT NULL,              -- sick | personal | vacation | other
  title           TEXT,
  start_date      DATE NOT NULL,
  end_date        DATE NOT NULL,
  is_all_day      BOOLEAN DEFAULT true,
  note            TEXT,
  created_at      TIMESTAMPTZ DEFAULT now(),
  updated_at      TIMESTAMPTZ DEFAULT now(),
  deleted_at      TIMESTAMPTZ
);
```

### 4.4 นัดหมาย / อีเวนต์

```sql
CREATE TABLE events (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID NOT NULL REFERENCES auth.users(id),
  title           TEXT NOT NULL,
  description     TEXT,
  start_at        TIMESTAMPTZ NOT NULL,
  end_at          TIMESTAMPTZ NOT NULL,
  is_all_day      BOOLEAN DEFAULT false,
  location        TEXT,
  color           TEXT,
  reminder_at     TIMESTAMPTZ,
  created_at      TIMESTAMPTZ DEFAULT now(),
  updated_at      TIMESTAMPTZ DEFAULT now(),
  deleted_at      TIMESTAMPTZ
);
```

**การตรวจ overlap:**
```sql
-- หานัดหมายที่เวลาซ้อนกับช่วงที่กำลังจะสร้าง
SELECT *
FROM events
WHERE user_id = $1
  AND deleted_at IS NULL
  AND start_at < $end_at
  AND end_at > $start_at;
```

## 5. UI บนปฏิทิน (มือถือ + เดสก์ท็อป)

### ตัวเลือกการแสดงผล (Filter บนปฏิทิน)
```
☑ วันหยุดประจำสัปดาห์
☑ วันหยุดประจำปี
☑ วันลา
☑ นัดหมาย
☑ บันทึก
☑ เป้าหมาย
☐ รายการการเงิน
```

### สีแนะนำ
| ประเภท | สี |
|--------|-----|
| วันหยุดประจำสัปดาห์ | เทาอ่อน |
| วันหยุดประจำปี | แดงอ่อน / ส้มอ่อน |
| วันลา | ม่วงอ่อน |
| นัดหมาย | น้ำเงิน |
| บันทึก | เหลืองอ่อน |
| เป้าหมาย | เขียว/ม่วง ตามที่ตั้ง |
| Overlap เตือน | ส้ม / แดง |

## 5.1 Desktop Calendar — Interaction เพิ่มเติม

### คลิกวันเดียว
- เปิดแผงด้านข้าง (หรือ modal) ของวันนั้น
- ทำได้ทันที:
  - อัปเดตยอดเป้าหมาย (Goal contribution)
  - เพิ่ม / แก้ไขนัดหมาย
  - เพิ่มบันทึก
  - ดูรายการการเงินของวันนั้น
  - สร้างวันลา

### Multi-select หลายวัน
- กด `Ctrl` / `Cmd` + คลิก เพื่อเลือกหลายวัน
- หรือคลิกแล้วลากเลือกช่วงวัน
- เมื่อเลือกหลายวันแล้ว กด “สร้างอีเวนต์” ได้เลย
- ใช้ได้กับ:
  - สร้างนัดหมายทั้งช่วง
  - สร้างวันลาหลายวัน
  - กำหนดช่วงวันเป้าหมายจากปฏิทิน

```
ตัวอย่าง:
เลือก 10–12 ก.ย. → สร้าง “ลาพักร้อน” 3 วัน
เลือก 15 ก.ย. + 22 ก.ย. → สร้างนัดหมาย 2 วันแยกกัน
```

### สร้างจดหมายลางาน + บันทึกลงระบบพร้อมกัน
1. เลือกวันลา (วันเดียวหรือหลายวัน ด้วย multi-select)
2. กด “สร้างใบลา”
3. ระบบเปิดฟอร์มจดหมายลางาน:
   - ประเภทการลา (ป่วย / กิจ / พักร้อน)
   - วันที่ลา (ดึงจากวันที่เลือกอัตโนมัติ)
   - เหตุผล
   - ชื่อผู้บังคับบัญชา / แผนก (ถ้ามี)
4. กดบันทึก → เกิดพร้อมกัน 2 สิ่ง:
   - บันทึก **วันลา** ลงในปฏิทินและระบบ
   - สร้าง **จดหมายลางาน** (ข้อความพร้อมใช้)
5. ผู้ใช้สามารถ:
   - คัดลอกข้อความ
   - ดาวน์โหลดเป็น PDF
   - ส่งต่อทางอีเมลได้

**ตัวอย่างโครงสร้างจดหมายลางาน (ภาษาไทย):**
```
วันที่ [วันที่เขียน]

เรื่อง ขอลา[ประเภท]

เรียน [ผู้บังคับบัญชา]

         ข้าพเจ้า [ชื่อ] ขอลา[ประเภท]
ตั้งแต่วันที่ [เริ่ม] ถึงวันที่ [สิ้นสุด]
รวม [จำนวน] วัน

เหตุผล: [เหตุผล]

จึงเรียนมาเพื่อโปรดพิจารณา

ขอแสดงความนับถือ
[ชื่อ]
```

## 6. ประโยชน์ที่ได้

- เห็นวันหยุดและวันลาชัด → วางแผนงานไม่ชน
- เห็นนัดหมายทับซ้อนทันที → ลดการนัดซ้อน
- คลิกวันบนเดสก์ท็อปแล้วอัปเดตเป้าหมาย / นัดหมายได้ทันที
- เลือกหลายวันสร้างอีเวนต์หรือใบลาได้รวดเร็ว
- สร้างจดหมายลางานพร้อมบันทึกวันลาในที่เดียว
- รวมเงิน + งาน + ชีวิต ในปฏิทินเดียว
- ใช้ได้ทั้งมือถือ (ดูเร็ว) และเดสก์ท็อป (ทำงานละเอียด)

---

## 7. ลำดับการทำที่แนะนำ

1. แสดงวันหยุดประจำสัปดาห์ + วันหยุดประจำปี (ข้อมูลระบบ)
2. เพิ่มนัดหมาย / อีเวนต์ พร้อมเวลา
3. ตรวจจับ overlap ตอนสร้าง
4. เพิ่มวันลา
5. ตัวเลือกเปิด-ปิดชั้นข้อมูลบนปฏิทิน
6. มุมมอง Week / Day แสดงแถบเวลาทับกัน
