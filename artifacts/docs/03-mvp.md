# MVP Scope — MyDesk

> เป้าหมาย MVP: ผู้ใช้สามารถ **บันทึกรายการการเงินและบันทึกประจำวันด้วยคำสั้น ๆ** ได้จริงบนมือถือ และดูสรุปวันนี้/เดือนได้

---

## เป้าหมายความสำเร็จของ MVP

ผู้ใช้สามารถทำสิ่งเหล่านี้ได้ครบภายใน 1 เซสชัน:

1. สมัคร/เข้าสู่ระบบ (หรือใช้แบบ guest/offline ก่อน)
2. พิมพ์คำสั้น ๆ แล้วบันทึกรายจ่าย/รายรับได้
3. บันทึกโน้ตหรืองานสั้น ๆ ได้
4. เห็นสรุปวันนี้และรายการล่าสุด
5. ดูรายการการเงินย้อนหลังและสรุปเดือน
6. ใช้งานได้แม้ไม่มีเน็ต (ข้อมูลเก็บในเครื่อง)

---

## In Scope (สิ่งที่ทำใน MVP)

### 1. Authentication
- [x] Email + Password (Supabase)
- [x] Guest / Offline mode (ใช้ได้โดยไม่ต้อง login ก่อน)
- [ ] Social Login (Google / Apple) → ทำในรอบถัดไปได้

### 2. Quick Capture
- [x] ช่องพิมพ์คำสั้น ๆ
- [x] Rule-based parser พื้นฐาน (ตัวเลข, คำสำคัญรายรับ/รายจ่าย, วันนี้/พรุ่งนี้)
- [x] Preview ก่อนบันทึก
- [x] บันทึกเป็น record ประเภท expense / income / note / task

### 3. Home / วันนี้
- [x] สรุปวันนี้ (รายรับ, รายจ่าย, สุทธิ)
- [x] รายการวันนี้
- [x] ปุ่มลัดไป Quick Capture

### 4. การเงิน
- [x] รายการทั้งหมด + กรองประเภท
- [x] สรุปเดือนปัจจุบัน
- [x] จัดการบัญชีเงินเบื้องต้น (เพิ่ม/แก้ไขชื่อบัญชี)
- [x] หมวดหมู่พื้นฐาน (อาหาร, เดินทาง, เงินเดือน ฯลฯ)

### 5. บันทึก / งาน
- [x] สร้างโน้ตและงานแบบสั้น
- [x] ทำเครื่องหมายงานเสร็จ
- [x] ดูรายการตามวัน

### 5.1 Goals / เป้าหมาย (พื้นฐาน — สำคัญ)
- [x] สร้างเป้าหมายการออมได้ (เช่น เก็บ 5,000 ใน 30 วัน)
- [x] สร้างเป้าหมายแบบนับวันสำเร็จได้ (เช่น วิ่ง 30 วัน ต้องได้อย่างน้อย 25 วัน)
- [x] แสดง Goal Card พร้อมความคืบหน้า `current / target` + เปอร์เซ็นต์
- [x] ไฮไลต์ช่วงวันของเป้าหมายบนปฏิทิน
- [x] เพิ่ม/แก้ไขยอด contribution รายวันผ่านการคลิกวันที่ในปฏิทิน
- [x] เมื่อทำสำเร็จก่อนกำหนด → ถามผู้ใช้ว่าจะทำต่อหรือปิดเป้าหมาย
- [x] เมื่อบรรลุเป้าหมาย → แสดงข้อความแสดงความยินดี + ให้กำลังใจ
- [x] รองรับเป้าหมายร่วมเบื้องต้น (เชิญคนอื่น + รวมยอดจากทุกคน)
- [x] สร้างคำเชิญ + ส่งข้อความเชิญ (ลิงก์ / รหัสเชิญ / แชร์ผ่าน LINE)
- [x] รองรับ Quick Capture สำหรับสร้าง goal และเพิ่มยอด/วันสำเร็จ

### 6. ข้อมูลและการซิงค์
- [x] Local database (SQLite)
- [x] โครงสร้างตาราง records + account_books + categories
- [x] ซิงค์กับ Supabase เมื่อ login แล้ว (basic)
- [x] Offline-first

### 7. อื่น ๆ
- [x] ตั้งค่าภาษา (ไทยเป็นหลัก)
- [x] ธีมสว่าง (Dark mode ทีหลังได้)
- [x] Export ข้อมูลเบื้องต้น (JSON)

## Out of Scope (ยังไม่ทำใน MVP)

- Voice input / Speech-to-text
- AI parse ขั้นสูง (LLM)
- Calendar view แบบ Week ละเอียดมาก
- โปรเจกต์ซับซ้อน + milestone หลายชั้น
- OAuth LINE / Facebook / TikTok
- Notification แบบ push ละเอียด
- Multi-currency
- งบประมาณ (Budget) แบบเต็มรูปแบบ + แจ้งเตือนเกินงบ
- การแชร์ข้อมูลกับคนอื่น
- Widget หน้าโฮม
- Desktop / Electron version
- เป้าหมายแบบ recurring อัตโนมัติระยะยาว (ทำทีหลังได้)

## User Stories หลักของ MVP

1. **ในฐานะผู้ใช้** ฉันต้องการพิมพ์ "กาแฟ 65" แล้วบันทึกเป็นรายจ่ายได้ทันที
2. **ในฐานะผู้ใช้** ฉันต้องการเห็นว่าวันนี้ใช้เงินไปเท่าไหร่โดยไม่ต้องคำนวณเอง
3. **ในฐานะผู้ใช้** ฉันต้องการจดโน้ตสั้น ๆ หรืองานที่ต้องทำควบคู่กับรายการเงิน
4. **ในฐานะผู้ใช้** ฉันต้องการใช้แอพได้แม้ไม่มีอินเน็ต
5. **ในฐานะผู้ใช้** ฉันต้องการให้ข้อมูลขึ้น cloud เมื่อฉัน login เพื่อไม่หายตอนเปลี่ยนเครื่อง
6. **ในฐานะผู้ใช้** ฉันต้องการตั้งเป้าหมาย “เก็บเงิน 5,000 ใน 30 วัน” แล้วเห็นการ์ดความคืบหน้า
7. **ในฐานะผู้ใช้** ฉันต้องการเห็นช่วง 30 วันของเป้าหมายถูกไฮไลต์บนปฏิทิน
8. **ในฐานะผู้ใช้** ฉันต้องการคลิกวันที่ในปฏิทินแล้วอัปเดตยอดที่เก็บได้ของวันนั้นได้
9. **ในฐานะผู้ใช้** ฉันต้องการให้ยอดรวมและความคืบหน้าบน Goal Card อัปเดตอัตโนมัติหลังบันทึกยอดรายวัน

## เกณฑ์พร้อมปล่อย MVP (Definition of Done)

- [ ] ติดตั้งบน Android + iOS (Expo) ได้
- [ ] Quick Capture ใช้งานได้จริงกับประโยคตัวอย่างอย่างน้อย 10 แบบ
- [ ] ข้อมูลไม่หายตอนปิดแอพ (local persist)
- [ ] Login แล้วซิงค์ข้อมูลขึ้น Supabase ได้
- [ ] ไม่มี crash ร้ายแรงใน flow หลัก
- [ ] UI ใช้ภาษาไทยได้ถูกต้อง

---

## ตัวชี้วัดความสำเร็จหลังปล่อย MVP (เบื้องต้น)

- ผู้ใช้บันทึกอย่างน้อย 5 รายการภายใน 3 วันแรก
- อัตราการใช้ Quick Capture สูงกว่าการเปิดฟอร์มเต็ม
- ผู้ใช้กลับมาใช้ซ้ำในสัปดาห์ถัดไป
