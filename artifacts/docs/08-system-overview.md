# MyDesk — System Overview (สรุปสถาปัตยกรรมรวม)

> รวมทุกส่วนที่ออกแบบไว้ให้เห็นภาพเดียว  
> การเงินต่อเนื่อง + เป้าหมายมีกำหนดเวลา + บัญชีร่วม + รายงาน

อัปเดตล่าสุด: 2 กันยายน 2026

---

## 1. วิสัยทัศน์รวม

MyDesk เป็นแอพมือถือที่ช่วยให้ผู้ใช้:

1. **บันทึกการเงินและชีวิตประจำวันได้เร็ว** ด้วยคำสั้น ๆ
2. **จัดการเงินหลายแหล่ง** (เงินสด, ธนาคาร, บัตรเครดิต, e-Wallet)
3. **ออมและตั้งเป้าหมาย** ทั้งแบบมีกำหนดเวลาและแบบสะสมต่อเนื่อง
4. **ทำงานร่วมกับคนอื่นได้** (แฟน / ครอบครัว)
5. **ดูภาพรวมได้ตามช่วงเวลา** (วัน / สัปดาห์ / เดือน / ปี)

## 3. สองระบบหลักที่ทำงานคู่กัน

### 3.1 Finance System — การเงินต่อเนื่อง

| รายการ | รายละเอียด |
|--------|-----------|
| จุดประสงค์ | จัดการเงินที่ใช้จริงในชีวิตประจำวัน |
| มีกำหนดเวลาไหม | **ไม่มี** (สะสมไปเรื่อย ๆ) |
| สิ่งที่รองรับ | หลายบัญชี, โอนข้ามบัญชี, บัญชีร่วม, รายงาน |
| ประเภทบัญชี | เงินสด, ธนาคาร, บัตรเครดิต, e-Wallet, ออม/สะสม |

**ตัวอย่างการใช้งาน:**
- มีเงินสด + บัญชีกสิกร + บัตรเครดิต + TrueMoney
- โอนจากบัญชีส่วนตัว → สะสมครอบครัว
- ดูสรุปรายรับ-รายจ่ายรายวัน/สัปดาห์/เดือน/ปี

### 3.2 Goal System — เป้าหมายมีกำหนดเวลา

| รายการ | รายละเอียด |
|--------|-----------|
| จุดประสงค์ | ตั้งเป้าแล้วติดตามให้ถึงภายในเวลา |
| มีกำหนดเวลาไหม | **มี** (start_date ~ end_date) |
| สิ่งที่รองรับ | ความคืบหน้า, ไฮไลต์ปฏิทิน, เชิญคนอื่น, แสดงความยินดี |
| ประเภทเป้าหมาย | ออมเงิน, นับวันสำเร็จ (habit), ปริมาณ |

**ตัวอย่างการใช้งาน:**
- เก็บเงิน 5,000 บาท ใน 30 วัน
- วิ่ง 30 วัน ต้องได้อย่างน้อย 25 วัน
- ทำสำเร็จก่อนเวลา → ถามว่าจะทำต่อหรือปิด
- สำเร็จแล้ว → แสดงข้อความให้กำลังใจ

## 4. การเชื่อมต่อระหว่างสองระบบ

```
ผู้ใช้โอนเงินเข้าบัญชีออม
         │
         ▼
ระบบถาม: “ให้นับเข้าเป้าหมายด้วยไหม?”
         │
    ┌────┴────┐
    │ ใช่     │ ไม่
    ▼         ▼
สร้าง        จบแค่
contribution  อัปเดต
ให้ Goal      บัญชี
```

- Transaction สามารถมี `goal_id` ได้
- ยอดโอนสามารถไปอัปเดตทั้ง `accounts.current_balance` และ `goals.current_value` พร้อมกัน

---

## 5. บัญชีหลายประเภท (เงินใช้จ่ายส่วนตัว)

ผู้ใช้คนหนึ่งสามารถมีบัญชีพร้อมกันได้หลายใบ:

| ประเภท | ตัวอย่าง | หมายเหตุ |
|--------|---------|---------|
| เงินสด | เงินในกระเป๋า | ใช้จ่าย日常 |
| ธนาคาร | กสิกร, ไทยพาณิชย์ | มีได้หลายบัญชี |
| บัตรเครดิต | บัตรกสิกร | ยอดใช้ = หนี้, มีวงเงิน |
| e-Wallet | TrueMoney, LINE Pay | กระเป๋าเงินดิจิทัล |
| ออม/สะสม | สะสมครอบครัว | รองรับผู้ใช้ร่วม |

**การโอนข้ามบัญชี:**
- โอนจาก A → B แล้วเกิดรายการเดินบัญชีทั้งสองฝั่ง
- ยอดคงเหลืออัปเดตทั้งสองบัญชี

---

## 6. การทำงานร่วมกัน (Shared)

ทั้งบัญชีและเป้าหมายรองรับการทำงานร่วมกัน:

| ฟีเจอร์ | Finance | Goal |
|--------|---------|------|
| มีเจ้าของ | ✅ | ✅ |
| เชิญคนอื่น | ✅ (account_invitations) | ✅ (goal_invitations) |
| สมาชิกหลายคน | ✅ (account_members) | ✅ (goal_members) |
| ส่งข้อความเชิญ | ✅ | ✅ |
| รวมยอดจากทุกคน | ✅ | ✅ |

**ตัวอย่าง:**  
ผม + แฟน ใช้บัญชี “สะสมครอบครัว” ร่วมกัน  
และมีเป้าหมาย “เก็บเงินเที่ยว 20,000 ใน 3 เดือน” ร่วมกันด้วย

## 7. มุมมองรายงานตามช่วงเวลา

รองรับทุกส่วนของการเงิน:

| ระดับ | ใช้ดูอะไรได้บ้าง |
|------|----------------|
| **รายวัน** | รายการวันนี้, สรุปใช้จ่ายวันนี้ |
| **รายสัปดาห์** | สรุปสัปดาห์ + เปรียบเทียบสัปดาห์ก่อน |
| **รายเดือน** | สรุปเดือน + สัดส่วนหมวดหมู่ |
| **รายปี** | ภาพรวมทั้งปี + แนวโน้ม |

สามารถเลือกได้ว่าจะดู:
- เฉพาะบัญชีหนึ่ง
- รวมทุกบัญชี
- เฉพาะรายรับ / รายจ่าย / โอน

## 8. ตารางฐานข้อมูลทั้งหมด (สรุป)

### Finance
| ตาราง | หน้าที่ |
|------|--------|
| `accounts` | บัญชีเงินทุกประเภท |
| `account_members` | สมาชิกบัญชีร่วม |
| `transactions` | รายการเดินบัญชี (รายรับ/รายจ่าย/โอน) |
| `account_invitations` | คำเชิญเข้าบัญชีร่วม |

### Goal
| ตาราง | หน้าที่ |
|------|--------|
| `goals` | เป้าหมายหลัก |
| `goal_members` | สมาชิกเป้าหมายร่วม |
| `goal_contributions` | ยอด/วันที่บันทึกเข้าเป้า |
| `goal_invitations` | คำเชิญเข้าเป้าหมาย |
| `celebration_messages` | ข้อความแสดงความยินดี |

### อื่น ๆ (จากแผนเดิม)
| ตาราง | หน้าที่ |
|------|--------|
| `records` | โน้ต / งาน / อีเวนต์ทั่วไป (ถ้ายังใช้ unified model) |
| `categories` | หมวดหมู่รายรับ-รายจ่าย |
| `settings` | การตั้งค่าผู้ใช้ |

## 9. หน้าจอหลักของแอพ (รวม)

```
[ วันนี้ ]  [ การเงิน ]  [ เป้าหมาย ]  [ ปฏิทิน ]  [ ฉัน ]
```

| หน้า | สิ่งที่แสดง |
|------|-----------|
| **วันนี้** | Quick Input + สรุปวันนี้ + รายการล่าสุด + Goal ที่ใกล้ถึงกำหนด |
| **การเงิน** | ยอดทุกบัญชี + รายการเดินบัญชี + สรุปตามช่วงเวลา + โอนเงิน |
| **เป้าหมาย** | Goal Cards + ความคืบหน้า + เป้าหมายร่วม |
| **ปฏิทิน** | ไฮไลต์ช่วง Goal + รายการตามวัน + อัปเดต contribution |
| **ฉัน** | บัญชีผู้ใช้, สมาชิก, ตั้งค่า, ซิงค์ |

## 10. Flow สำคัญที่รวมทุกส่วน

### Flow 1: ใช้จ่ายประจำวัน
```
ซื้อกาแฟ 65 บาท (เงินสด)
  → บันทึก expense เข้าบัญชีเงินสด
  → ยอดเงินสดลด
  → ปรากฏในสรุปรายวัน
```

### Flow 2: โอนเข้าออม + นับเข้าเป้า
```
โอน 2,000 จากบัญชีกสิกร → สะสมครอบครัว
  → เกิดรายการโอนทั้ง 2 บัญชี
  → ถามว่าให้นับเข้าเป้าหมาย “เก็บเงินเที่ยว” ไหม
  → ถ้าใช่ → อัปเดต Goal Card
```

### Flow 3: เป้าหมายร่วม
```
สร้างเป้าหมาย “เก็บเงินเที่ยว 20,000 ใน 90 วัน” (shared)
  → เชิญแฟน (ส่งข้อความ + ลิงก์)
  → แฟนยอมรับ
  → ทั้งสองคนใส่ยอดได้
  → ความคืบหน้ารวมกัน
  → สำเร็จแล้วแสดงข้อความยินดีร่วมกัน
```

### Flow 4: ดูภาพรวมรายเดือน
```
เลือก “เดือนนี้”
  → เห็นรายรับ / รายจ่าย / สุทธิ
  → เห็นสัดส่วนหมวดหมู่
  → เห็นยอดโอนเข้าออม
  → เปรียบเทียบกับเดือนที่แล้วได้
```

## 11. หลักการออกแบบที่ยึดตลอด

1. **เร็ว** — บันทึกด้วยคำสั้น ๆ ได้ในไม่กี่วินาที
2. **รวม** — เงินหลายแหล่ง + เป้าหมาย + คนอื่น อยู่ในที่เดียว
3. **ชัด** — แยก “บัญชีต่อเนื่อง” กับ “เป้าหมายมีเวลา” ให้เข้าใจง่าย
4. **ยืดหยุ่น** — ดูรายงานได้หลายช่วงเวลา ตามที่ต้องการ
5. **ร่วมกันได้** — เชิญคนอื่นเข้าทั้งบัญชีและเป้าหมาย
6. **Offline-first** — ใช้ได้แม้ไม่มีเน็ต แล้วค่อยซิงค์
