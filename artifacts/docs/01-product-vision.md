# MyDesk / เลขาการเงิน + บันทึกประจำวัน

> แอพมือถือที่รวม **การเงินส่วนตัว** กับ **การจดบันทึกประจำวัน / งาน** เข้าด้วยกัน  
> สั่งงานด้วยคำสั้น ๆ • บันทึกเร็ว • ฉลาด • แม่นยำ

---

## วิสัยทัศน์ (Vision)

สร้างผู้ช่วยส่วนตัวบนมือถือที่ช่วยให้ผู้ใช้:

1. **บันทึกรายการการเงินได้ภายใน 5-10 วินาที** ด้วยคำสั้น ๆ
2. **จดบันทึกประจำวัน / งาน / นัดหมาย** ได้รวดเร็วและเป็นระบบ
3. **เห็นภาพรวมชีวิต** ทั้งเงินและกิจกรรมในที่เดียว
4. **ทำงานได้แม้ไม่มีเน็ต** (Offline-first)
5. **ซิงค์ข้ามอุปกรณ์** เมื่อมีเน็ต (ผ่าน Supabase)

---

## ปัญหาที่ต้องการแก้

| ปัญหา | ผลกระทบ |
|-------|---------|
| ต้องเปิดหลายแอพ (แอพการเงิน + โน้ต + ปฏิทิน) | เสียเวลา + ข้อมูลกระจัดกระจาย |
| บันทึกรายจ่ายช้า / ขี้เกียจบันทึก | ข้อมูลไม่ครบ → วิเคราะห์ไม่ได้ |
| ต้องกรอกฟอร์มยาว | ผู้ใช้เลิกใช้เร็ว |
| ไม่มีบริบทเชื่อมโยงระหว่างเงินกับชีวิตประจำวัน | มองไม่เห็นภาพรวม |

## แนวคิดหลัก (Core Concepts)

- **Quick Capture**: พิมพ์หรือพูดคำสั้น ๆ แล้วระบบแปลงเป็น record ที่ถูกต้อง
- **Unified Record**: ทุกรายการ (เงิน / งาน / โน้ต / นัด / เป้าหมาย) อยู่ในโครงสร้างเดียวกัน
- **Smart Defaults**: เดาหมวดหมู่, บัญชี, วันที่ จากพฤติกรรมและความหมายของคำ
- **Daily Context**: เห็นทั้งรายรับ-รายจ่ายและบันทึกประจำวันในหน้าเดียว
- **Goal with Progress**: ตั้งเป้าหมาย (โดยเฉพาะการออม) แล้วติดตามความคืบหน้ารายวันบนการ์ดและปฏิทิน
- **Privacy + Sync**: ข้อมูลอยู่บนเครื่องเป็นหลัก + ซิงค์ขึ้น cloud เมื่อต้องการ

## กลุ่มเป้าหมาย

- คนทำงานที่อยากควบคุมการเงินและชีวิตประจำวันแบบง่าย ๆ
- คนที่เคยลองแอพการเงินแล้วเลิกใช้เพราะกรอกยาก
- คนที่จดโน้ตและรายจ่ายแยกกันอยู่แล้ว อยากรวมเป็นที่เดียว

## หลักการออกแบบผลิตภัณฑ์

1. **เร็วเป็นอันดับแรก** — บันทึกต้องเสร็จในไม่กี่วินาที
2. **คำสั้น ๆ ก็พอ** — ไม่บังคับกรอกฟอร์มยาว
3. **ฉลาดแต่ไม่ก้าวก่าย** — แนะนำได้ แต่ผู้ใช้แก้ไขง่าย
4. **Offline-first** — ใช้งานได้ทุกที่
5. **ข้อมูลเป็นของลูกค้า** — โปร่งใสเรื่องการเก็บข้อมูล
